Shape and size

Controls and buttons are 32px tall with 8px corners. 44px on touch screens.

Dialogs and drawers: 12px corners. Badges: 4px. Toggles: round.

Every pane header is 56px, so their bottom lines meet.

Depth and motion

Panes and cards sit flat. Menus and popovers get the small shadow; dialogs and drawers the large one.

Motion is 150ms, only for state changes, and it turns off when the reduced-motion setting is on.

Controls in every state

Focus is shown here with a fixed ring so you can see it without a keyboard.

Actions

One primary per area. A busy button keeps its label and blocks only itself.

Picture tiles

When the options differ in how something looks, show a small picture of each one instead of a dropdown. Same recipe as today's Appearance picker: art, a short name, a tick when chosen, arrow keys move. Use a dropdown only when there are too many options or they have no look to draw.

Feedback, loading, empty, failed

Loading, empty and failed always use different words and different actions. A failed load never looks like an empty list.
