Built-in words (Next, Back, “This field is required”) are translated once for the whole org in Setup → Translation Workbench, not per form.

  • Translate sits next to Build and Design in the top bar; English is edited only in Build.
  • Rows come from the form itself (no keys to type, nothing to import). Typing saves like the rest of the Studio.
  • Check = the English changed after this was translated; the old English is shown so the translator sees what moved.
  • “Needs work” = missing + changed. Choice options are listed by their stored value, so renaming a label keeps the translation.
  • Preview in French opens the preview with that language (the ?lang= path that already works).
