Address search
Suggests addresses as people type, using Google Places. Every search counts against your organisation's Google account. Public forms get a limited number of searches per visit.
If search isn't set up: “No address search is set up for your organisation, so people type the address. An admin can set it up on the Settings tab.” (switch shown off and disabled)
D. Studio: palette item Freeform “Questions” group / Survey list

New palette item Address (icon utility:location), title “A postal address, with optional address search”.

Freeform mapping: the answer offers its parts as sources (Address → Street, City, State / Province, Zip / Postal code, Country, Country code, Latitude, Longitude) so each can be mapped to a field, e.g. MailingCity.

Survey: the answer is kept as one row with the parts inside; the response viewer shows it as a formatted address.

Address search

Suggest addresses while people fill in Address questions. You bring your own account with the provider; your key stays in Salesforce and is never sent to anyone filling in a form.

Provider
Google Places
None · Google Places · Loqate · Your own (Apex class)

Connect your key

  1. In Setup, open Named Credentials → External Credentials → Final Address Google.
  2. Under Principals, edit Key and paste your Google API key.
  3. Give the Form Builder Admin and your public site's guest user permission set access to that principal (only needed for public forms).
