  • Wording: question name (a link) + the same message the question shows in red. Heading "Please fix these to submit:" / "…to continue:" depending on the button.
  • Long lists: first 5, then "and N more" (the rest are still red on the page).
  • Related lists: "References, entry 2: Email".
  • Guests: our own checks on their answers show the question and message (it's what the browser already tells them). An org validation rule or a lookup refusal stays one plain line: "Your response could not be saved. Nothing was recorded." (a public form must not reveal the org's rules).
  • One at a time layouts keep their top banner, but it lists the same way.
  • Screen readers hear the heading and the list once (alert), not every question's message at once.
